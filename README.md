# Namera

Namera is an AI-powered baby-naming platform designed to help parents discover names with meaning, cultural context, pronunciation, and family fit.

## Project direction

This project follows the master brief in [docs/NAMERA_PROJECT_BRIEF.md](docs/NAMERA_PROJECT_BRIEF.md). The product is meant to be more than a name list: it should help parents understand why a name suits them and make decisions with confidence.

## Current status

The frontend foundation is now in place and the app builds successfully.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- shadcn-inspired UI primitives

## Run locally

```bash
cd apps/web
npm install
npm run dev
```

Then open http://localhost:3000

## Deployable baseline

The current production build passes:

```bash
cd apps/web
npm run build
```
